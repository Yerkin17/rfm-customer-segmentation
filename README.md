# rfm-customer-segmentation
RFM analysis of online retail customer base using Python and Pandas
# 🛒 RFM-анализ и сегментация клиентов интернет-магазина

## 📌 О проекте
Пет-проект по сегментации клиентской базы на основе транзакционных данных ритейлера. Анализ позволяет выявить ключевых клиентов (VIP), группы риска и ушедшую аудиторию для точечных маркетинговых кампаний.

## 🛠 Технологии и стек
* **Python** (Pandas, NumPy, Matplotlib)
* **Jupyter Notebook**
* **RFM-методология** (Recency, Frequency, Monetary)

## 📊 Основные этапы реализации
1. **Очистка данных:** Удаление пропусков в `CustomerID`, фильтрация возвратов (`Quantity > 0`), преобразование типов дат.
2. **Расчет метрик:** Агрегация данных в разрезе клиентов с вычислением давности (`Recency`), частоты (`Frequency`) и суммы покупок (`Monetary`).
3. **Скоринг и Сегментация:** Квантильное ранжирование клиентов от 1 до 5 и распределение по бизнес-сегментам (*Champions, Loyal Customers, At Risk, Hibernating / Lost*).
4. **Визуализация:** Построение графика распределения клиентских сегментов.

## 📂 Структура репозитория
* `Untitled.ipynb` - Jupyter Notebook с полным кодом анализа.
* `rfm_segmented_data.csv` - готовый датасет с рассчитанными метриками и сегментами.

## 💡 Бизнес-инсайты (Пример выводов)
* Сегмент **Champions** генерирует наибольшую долю выручки и требует программ лояльности.
* Сегменты **At Risk** и **Hibernating** требуют реактивационных email-рассылок со скидками, так как давно не совершали покупок.
